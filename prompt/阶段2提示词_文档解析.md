## 本阶段任务

### 1. 统一输出数据结构

```python
@dataclass
class ParsedBlock:
    page: int             # 逻辑页码(从1开始;Word填0)
    block_index: int      # 全文顺序号(按正确阅读顺序)
    text: str
    block_type: str       # 'paragraph' / 'heading' / 'footnote' / 'table' / 'figure_caption' / 'other'
    source_location: str  # 如 "第3页左栏" / "第5段"
    ocr_confidence: float | None  # OCR置信度(0~1),非OCR文本填None

@dataclass
class ParsedDocument:
    file_name: str
    file_type: str        # 'pdf' / 'docx'
    total_pages: int      # 逻辑页数;Word填段落总数
    blocks: list[ParsedBlock]
    layout_mode: str      # 'single' / 'double' / 'mixed'(Word填'single')
    text_source: str      # 'native' / 'ocr' / 'mixed'
    warnings: list[str]
```

### 2. 解析流程(PDF)

```
打开PDF → 逐页文字层检测
   ├─ 有文字层 → A类流程:PyMuPDF按坐标提取文本块
   └─ 无文字层 → B类流程:
        渲染页面为图片(建议200~300dpi)
        → 跨页检测与拆分(3.1)
        → PaddleOCR 识别 + 版面分析(3.2)
两类结果统一 → 阅读顺序还原(4) → ParsedDocument
```

文字层检测:该页可提取字符数低于阈值(如20字)视为无文字层。同一文档允许混合(text_source='mixed')。

### 3. B类流程:PaddleOCR

**技术选型:PaddleOCR(中文模型)**,理由:中文识别准确率优于 Tesseract;PP-Structure 版面分析可直接输出区域类型(text/title/figure/table/figure_caption)与坐标,用于分栏判断和过滤图片区域。



**3.2 识别与版面分析**
- 对每个逻辑页调用 PaddleOCR,得到带坐标(bbox)、文本、置信度的识别结果
- **分栏与阅读顺序**(关键):
  - 判断单/双栏:可结合版面分析的区域x坐标分布,或用列像素密度分析(统计每列暗像素,页面中部40%~60%宽度存在低密度竖直空白带→双栏,空白带最低点为分栏线)。两种方法择优,以双栏样本实测阅读顺序正确为准
  - 双栏:输出顺序 = 左栏(上→下)→ 右栏(上→下)
  - 单栏:按y坐标上→下
- 每块记录 PaddleOCR 返回的置信度(0~1);整页平均置信度低于阈值写warnings

**3.3 跨页检测与拆分**
- 页面宽高比明显大于1(横版)且左右内容独立 → 跨页,水平中线切成左右两个逻辑页,左前右后
- 参数 `spread_order`('normal'/'cover_first'),默认'normal';封面封底不自动识别,warnings 提示首页需人工确认
- 本次四份样本可能不含跨页,该逻辑仍需实现(实际期刊会遇到)

**3.4 结果清洗**
- 合并被切碎的行为段落(按行距、缩进/bbox间距判断边界)
- 剔除页眉页脚页码(位置+多页重复文本)
- 图片/复杂背景区域的乱码:对残留的极低置信度、极短无意义文本块仍做丢弃,warnings 记录"第N页存在被过滤的低质量识别区域"

### 4. A类通道的分栏与阅读顺序还原

- 逐页判断单/双栏(文本块中心x坐标聚类:两簇+稳定空白带→双栏)
- 双栏:左栏上→下,再右栏上→下;跨栏元素按y坐标插入
- 单栏:按y坐标排序
- 低置信度页写warnings;保留 `force_layout`('auto'/'single'/'double')

(A/B 两通道分栏思路一致,作用对象不同:A类作用于文本块坐标,B类作用于图像/版面区域。)

### 5. C类:Word 解析(python-docx)

按段落顺序读取,标题层级映射block_type,跳过空段落,不读页眉页脚。

### 6. 对外接口

```python
def parse_document(
    file_path: str | Path,
    force_layout: str = 'auto',
    spread_order: str = 'normal',
    ocr: str = 'auto',   # 'auto'检测 / 'force'强制OCR / 'off'禁用(无文字层则报错)
) -> ParsedDocument: ...
```

不支持格式抛 `UnsupportedFormatError`;ocr='off' 且无文字层抛 `NoTextLayerError`。

### 7. 调试辅助脚本

`tools/preview_parse.py`:传入文件路径,打印每块一行预览(`[逻辑页码][位置][类型][OCR置信度] 文本前50字`),结尾输出 layout_mode、text_source、warnings。

### 8. 测试(tests/test_stage2.py)——以交叉验证为核心

**基础断言**:
- sample.docx:file_type='docx',段落顺序正确,空段落剔除
- sample.pdf:text_source='native'(**不得走OCR**),layout_mode='single'
- sample_single_column.pdf:text_source='ocr',每块 ocr_confidence 非空,layout_mode='single'
- sample_double_column.pdf:text_source='ocr',layout_mode='double'
- ocr='off' 对 B类样本抛 NoTextLayerError

**交叉验证一:A类 vs C类(内容相同)**
- 提取 sample.pdf 与 sample.docx 全文(拼接所有block),归一化后相似度≥95%(difflib.SequenceMatcher)

**交叉验证二:双栏OCR vs 单栏OCR(内容相同)★最关键**
- 提取两份B类样本全文,归一化后计算相似度
- 串栏会导致顺序大面积错乱、相似度显著下降,是分栏还原正确性的量化检验
- 阈值:≥88%(若实测达不到,报告实际值与差异样例,不要偷偷调低阈值)

**报告要求**:测试输出两组交叉验证的实际相似度数值。
