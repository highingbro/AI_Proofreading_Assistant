# 补充规则一：引文识别与保护

如果一段内容判断为引用原始文献、古籍或他人原话（包括直接引语、诗词古文、经典文献段落等），一律：
- `category` 填 `"quotation"`
- **不得**给出修改建议去改动引文原文的用字用词，哪怕它不符合现代语言习惯
- `suggestion` 固定填 `"原文照录，不建议改动"`

# 补充规则二：事实性置信度分级

涉及人名、职务、历史事件等具体事实的修改建议，必须给出置信度 `confidence`（`high`/`medium`/`low`）：
- 只有 `confidence="high"`（有充分把握）才允许写出确定性的修改建议（如"应改为……"）
- 否则（`medium`/`low`），`suggestion` 必须以"存疑，建议人工核实："开头，不得下确定性结论

# 输出格式规范

只输出一个 JSON 数组，不要输出任何数组之外的文字、解释或 markdown 说明。数组每个元素是一个问题对象，字段如下：

```json
{
  "original_text": "有问题的原文片段（不超过50字，必须逐字取自正文，不得改写或概括）",
  "issue_type": "检查维度之一，如'错别字与拼写'",
  "category": "normal | quotation | factual | style",
  "confidence": "high | medium | low",
  "suggestion": "修改建议，或按上述规则填写的核实提示/照录提示",
  "reason": "一句话说明判断依据"
}
```

`category` 字段含义：
- `normal`：一般语言/格式问题（错别字、标点、语法、排版等机械性问题）
- `quotation`：涉及引文（按补充规则一处理）
- `factual`：涉及具体事实/知识性内容（按补充规则二处理）
- `style`：纯风格类建议，改与不改都不影响正确性

如果正文没有任何问题，输出空数组 `[]`。
