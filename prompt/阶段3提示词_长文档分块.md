## 模块定位

输入:阶段2产出的 `ParsedDocument`
输出:一组"分块"(chunk),每块将在阶段4作为一次LLM校对调用的正文内容

设计目标按优先级排序:
1. **可回溯**:每条校对问题最终要标注"页码/位置",分块必须保留到 ParsedBlock 的映射,不能把定位信息切丢
2. **不切断语义单元**:不在段落中间硬切;引文、表格块尽量保持完整(引文被切断会破坏阶段5的引文识别)
3. **跨块问题不漏检**:块间保留上下文重叠
4. 块大小适配LLM上下文限制

## 本阶段任务

### 1. 数据结构

```python
@dataclass
class Chunk:
    chunk_index: int              # 分块序号,从0开始
    text: str                     # 送给LLM的正文(由若干block的text拼接)
    block_indices: list[int]      # 本块包含的 ParsedBlock.block_index 列表(不含重叠区)
    overlap_prefix_blocks: list[int]  # 前向重叠区的 block_index(仅作上下文,其上问题不在本块报告)
    page_range: tuple[int, int]   # 本块覆盖的逻辑页码范围(含重叠区)
    char_count: int               # text 字符数

@dataclass
class ChunkedDocument:
    source: ParsedDocument        # 引用原解析结果(或其必要元信息)
    chunks: list[Chunk]
    chunk_size_target: int        # 本次分块使用的目标块大小
    overlap_blocks: int           # 本次使用的重叠块数
    warnings: list[str]           # 如"第N块因单个超长块超出目标大小"
```

### 2. 分块规则

**2.1 大小控制**
- 以**字符数**为度量(中文场景下字符数与token近似线性,不引入tokenizer依赖)
- 目标块大小 `CHUNK_SIZE_TARGET` 与硬上限 `CHUNK_SIZE_MAX` 进 config.py,默认值建议 3000 / 4500 字符(阶段4接入具体模型后可能调整,所以必须可配)
- 贪心装填:按 block_index 顺序累加 block,加入下一个 block 会超过目标大小时收束当前块

**2.2 边界规则(核心)**
- **只在 block 边界切分**,永不在 block 内部切断
- 例外:单个 block 自身超过 CHUNK_SIZE_MAX(如超长段落)时,允许在句号/问号/叹号处切分该 block,切分处写入 warnings,且两半都保留原 block_index 映射
- block_type='heading' 尽量作为新块的开头而不是上一块的结尾(标题跟随其后内容)
- block_type='table' 保持完整,不与切分例外规则混用;表格自身超过 CHUNK_SIZE_MAX 时整块单独成chunk并写warnings

**2.3 重叠规则**
- 每个块(除第一块)携带前一块末尾的 N 个 block 作为"前向重叠区"(`OVERLAP_BLOCKS` 进 config.py,默认2个block)
- 重叠区在 text 中位于开头,并用明确分隔标记包裹,例如:

```
【上文回顾,仅供理解上下文,此部分的问题不要报告】
……(重叠区文本)……
【正文开始,请校对以下内容】
……(本块正文)……
```

- 标记文案定义为 config.py 常量(阶段4的提示词会引用同一常量,保持一致)
- overlap_prefix_blocks 与 block_indices 严格区分,为阶段4/5做"重叠区问题去重"提供依据

**2.4 顺序与完整性**
- 所有 block 必须且仅被一个 chunk 的 block_indices 收录(重叠区除外),不遗漏、不重复
- chunk 顺序与 block 顺序一致

### 6. 测试(tests/test_stage3.py)

用阶段2的真实样本(经 parse_document 得到 ParsedDocument)加构造的合成 ParsedDocument(直接手工构造 blocks 列表,便于精确断言):

**完整性**:
- 所有 block_index 恰好被收录一次(集合相等断言)
- chunk 内与 chunk 间的 block 顺序单调递增

**边界**:
- 无 block 被切断(除超长例外);构造一个含超长 block 的合成文档,验证在句末切分、warnings 有记录
- 构造 heading 恰好落在块尾的场景,验证 heading 被推到下一块开头
- 每个 chunk 的 char_count ≤ CHUNK_SIZE_MAX

**重叠**:
- 第2块起 overlap_prefix_blocks == 前一块 block_indices 的末尾N个
- text 中重叠标记格式正确(开头是回顾标记,正文标记之后是本块内容)

**定位**:
- chunk_for_block 对任意 block 返回正确 chunk
- page_range 与实际覆盖页码一致

**真实样本冒烟**:
- 对 sample_double_column.pdf 的解析结果跑分块,不抛异常,块数≥1,完整性断言通过
